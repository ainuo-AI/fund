# 基金信息站

一个用 Python + Flask 写的基金信息查询网站：搜索基金、查看基本信息、净值走势图和历史净值，还可以把基金加入"自选"、查看最近搜索记录。

## 项目结构

```
jijin/
├── app.py            # 网站入口：定义路由（网址 -> 页面）
├── fund_api.py       # 数据层：封装第三方接口，获取基金数据
├── templates/        # HTML 模板（Jinja2）
│   ├── base.html     #   公共骨架：导航栏 + 页脚
│   ├── index.html    #   首页：搜索框 + 热门基金卡片
│   ├── search.html   #   搜索结果页
│   ├── fund.html     #   基金详情页：信息 + 走势图 + 历史净值表
│   └── 404.html
├── static/
│   ├── style.css     # 全站样式
│   └── echarts.min.js# 图表库（已下载到本地，无需联网加载）
└── venv/             # Python 虚拟环境（依赖都装在这里）
```

## 如何启动

```bash
cd ~/Desktop/jijin
venv/Scripts/python app.py
```

然后浏览器打开 http://127.0.0.1:5000

停止服务：在运行窗口按 `Ctrl + C`。

## 页面与路由

| 网址 | 页面 | 对应函数 |
|---|---|---|
| `/` | 首页（我的自选 + 热门基金 + 最近搜索） | `index()` |
| `/search?q=关键词` | 搜索结果 | `search()` |
| `/fund/161725` | 基金详情（可加自选） | `fund_detail()` |
| `/api/funds?codes=161725,...` | 批量查最新净值（JSON 接口） | `api_funds()` |

## 自选基金

在基金详情页点"☆ 加入自选"，首页顶部就会出现"我的自选"卡片。
自选列表保存在浏览器的 localStorage 里（键名 `myFunds`），不需要数据库、不需要登录，
关掉浏览器也不会丢；但换浏览器或清浏览器数据后会消失。

## 搜索历史

首页搜索框下方会显示"最近搜索"标签（最多 8 条，最新在前），点击标签直接再搜，可一键清空。
历史记录在打开搜索结果页时自动写入 localStorage（键名 `searchHistory`），规则和自选一样：
只存在本浏览器，不需要服务器参与。

## 数据来源

均为公开免费接口，仅用于学习：

- 天天基金移动端 API：最新净值、历史净值
- 天天基金搜索建议：按名称/代码搜索
- 新浪财经：基金概况（类型、规模、公司、经理）

## 可以练手的改进方向

1. 首页热门基金换成你自己关注的代码（改 `app.py` 里的 `HOT_FUND_CODES`）
2. 给详情页加"近1月/近1年"区间涨跌幅统计
3. 用 `fund_api.get_nav_history` 做定投收益模拟计算
